Rotor DK8DE – Webflasher

ESP32-S3 per Browser flashen (Chrome/Edge, USB).

Version: —

Der USB-Webflasher schreibt factory.bin (Komplettimage ab Adresse 0 – Erstinstallation / Full-Flash).

Downloads

  • factory.bin – Komplettflash (USB-Webflasher / esptool, ab 0x0)
  • firmware.bin – nur App für SoftAP-OTA (Web-Tab Update)

SoftAP-OTA (WLAN-Update)

Per RS485 SETWLAN:1 Hotspot starten (Rotor_<UID> / Passwort Rotorconfig), dann http://192.168.4.1 (Login admin / Rotorconfig) → Tab Update → nur firmware.bin hochladen (nicht factory.bin).

esptool (Komplettflash)

esptool.py --chip esp32s3 write_flash 0x0 factory.bin
